# PR B4 — Numbers and comparisons (metric evidence, counters, bars, before/after) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Numbers a run measured (a demo command's printed lines, a response's JSON fields, a step's changed pixels, the diff's totals, the test run's output) become `metric:<source>:<name>` evidence with base and head values; a direction's `metric` element draws one as a counter, bars, or a before/after comparison, a `count` beat ticks it from before to after, and Covi's default director counts a terminal scene's biggest change, so the benchmark's request bytes count down from 70,406 to 9,907 as the largest thing on screen.

**Architecture:** Core gains a pure reader (`packages/core/src/evidence/metrics.ts`) that turns redacted text into named readings, and `buildEvidence` pairs base and head readings into additive `metric` items (`evidence.json` stays `schemaVersion: 1`, R-010). The direction file gains a `metric` element and a `count` verb whose values come only from those items; the resolver copies values and units and computes the delta itself; a new runtime module draws counters, bars, and comparisons as pure functions of the clock with Covi's own number formatting (`runtime/numbers.ts`, shared DOM-free with Node). The default director gives a terminal scene a `[metric, visual]` shot for the metric whose magnitude changed most.

**Tech Stack:** TypeScript on Node 22.18+ (type stripping, no build step), Zod 4, Vitest 5, Playwright Chromium, ffmpeg, Biome; the browser runtime is bundled by esbuild.

**Spec:** `~/projects/covi-0.3.0-program/docs/superpowers/specs/2026-10-09-covi-0.3.0-program-design.md` — §7 (numbers), §4 (direction file: §4.2 `metric`, §4.3 `count`, §4.6 validation, §4.7 resolution, §4.8 default director), §14–§18. Rulings ledger: `~/projects/covi-0.3.0-program/docs/superpowers/rulings.md` (R-010 metric evidence is additive; R-013 counts come only from metric evidence; R-015/R-019 label allowlist; R-017 CHANGELOG subsection). Code worktree: `~/projects/covi-direction`, branch `metrics`, started from the latest `main` after B1, B2, and B3 merged.

```ts
/** Bounds on measured numbers (`metric` items), and on reading them from a run's text. */
export const METRIC_LIMITS = {
  /** Metrics one source (a command, a response, a step, the diff, the test run) gives. */
  perSource: 50,
  /** Metrics one run gives. */
  perRun: 500,
  /** A metric's name in its id: a slug. */
  nameChars: 40,
  /** What the output called it, as kept in the item's label. */
  labelChars: 60,
  /** Values stay below this in magnitude, with at most `decimals` digits after the point. */
  magnitude: 1e15,
  decimals: 6,
  /** How deep numeric leaves of JSON output are read. */
  jsonDepth: 4,
  /** Characters of one text read for metrics, and the longest line read. */
  textChars: 100_000,
  lineChars: 200,
} as const;

/** Digits after the point, as JavaScript writes the number (an exponent counts as too many). */
export function decimalsOf(value: number): number {
  const text = String(value);
  if (/e/i.test(text)) return Number.POSITIVE_INFINITY;
  return text.split('.')[1]?.length ?? 0;
}

/** A value a metric may hold: finite, below 1e15 in magnitude, at most six decimals. */
export function isMetricValue(value: number): boolean {
  return (
    Number.isFinite(value) &&
    Math.abs(value) < METRIC_LIMITS.magnitude &&
    decimalsOf(value) <= METRIC_LIMITS.decimals
  );
}
```

```ts
import { isMetricValue, METRIC_LIMITS } from '../model/evidence.ts';

/*
 * Numbers measured in a run's own text: a demo command's output, a response body, the test run's
 * output. Pure and deterministic. Silence over noise: a line counts only when it is a name and a
 * number (and a unit) and nothing else, so versions, times, dates, and paths give nothing.
 */

/** One number read from one text. */
export interface MetricReading {
  /** Its slug, unique in its text: `request-bytes`, then `request-bytes-2` for a second one. */
  name: string;
  /** What the text called it, as printed: `request bytes`, or a JSON path, `data.total`. */
  label: string;
  value: number;
  unit?: string;
}

/** A metric of one source, its base and head readings paired by name. */
export interface PairedMetric {
  name: string;
  label: string;
  unit?: string;
  base?: number;
  head?: number;
}

/** Digits, grouped by commas, underscores, or thin or no-break spaces (one kind throughout). */
const NUMBER = String.raw`[+\-−]?(?:\d{1,3}(?:,\d{3})+|\d{1,3}(?:_\d{3})+|\d{1,3}(?:[   ]\d{3})+|\d+)(?:\.\d+)?`;
const UNIT = String.raw`%|\p{L}{1,8}`;
/** A whole line that names one number: `request bytes: 70406`, `- Duration = 1.2 s`, `Coverage: 87%`. */
const LINE = new RegExp(
  String.raw`^(?:[-*•]\s+)?(\p{L}[\p{L}\p{N} _./()'-]{0,59}?)\s*[:=]\s*(${NUMBER})\s*(${UNIT})?$`,
  'u',
);
/** `key=value` pairs inside a line: `status=200 duration=12ms`. */
const PAIR = new RegExp(
  String.raw`(?<=^|[\s,;(\[{])([A-Za-z_][A-Za-z0-9_.-]{0,39})=(${NUMBER})(${UNIT})?(?=$|[\s,;)\]}])`,
  'gu',
);
/** Terminal colors and cursor moves, which commands print around their numbers. */
const ANSI = /\u001b\[[0-9;?]*[ -/]*[@-~]/g;

/** A number as printed, as a metric value: separators dropped, rounded to six decimals. */
export function metricValue(text: string): number | undefined {
  const plain = text.replace(/[,_   ]/g, '').replace('−', '-');
  const value = Number(plain);
  if (!Number.isFinite(value)) return undefined;
  const rounded = Number(value.toFixed(METRIC_LIMITS.decimals)) || 0;
  return isMetricValue(rounded) ? rounded : undefined;
}

/**
 * A metric's name for its id: lowercase ASCII letters and digits, dashes between words, at most 40
 * characters. Empty when the label has no such letters (a label in another script); the label
 * itself keeps what the text said.
 */
export function metricSlug(label: string): string {
  return label
    .normalize('NFKD')
    .replace(/\p{M}/gu, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, METRIC_LIMITS.nameChars)
    .replace(/-+$/, '');
}

/** Gives each reading a name unique in its text, in order, and stops at the per-source cap. */
function named(found: Array<Omit<MetricReading, 'name'>>): MetricReading[] {
  const seen = new Set<string>();
  const out: MetricReading[] = [];
  for (const reading of found) {
    if (out.length >= METRIC_LIMITS.perSource) break;
    const slug = metricSlug(reading.label) || 'value';
    let name = slug;
    for (let n = 2; seen.has(name); n++)
      name = `${slug.slice(0, METRIC_LIMITS.nameChars - String(n).length - 1).replace(/-+$/, '')}-${n}`;
    seen.add(name);
    out.push({ name, ...reading });
  }
  return out;
}

const label = (text: string) =>
  text.replace(/\s+/g, ' ').trim().slice(0, METRIC_LIMITS.labelChars).trimEnd();

/** Numeric leaves of a JSON object, by key path, down to `jsonDepth`; arrays are not read. */
function leaves(value: unknown, path: string[], out: Array<Omit<MetricReading, 'name'>>): void {
  if (out.length >= METRIC_LIMITS.perSource) return;
  if (typeof value === 'number' && path.length) {
    const v = metricValue(String(value));
    if (v !== undefined) out.push({ label: label(path.join('.')), value: v });
    return;
  }
  // Arrays hold records, whose numbers are ids and amounts rather than measurements.
  if (!value || typeof value !== 'object' || Array.isArray(value)) return;
  if (path.length >= METRIC_LIMITS.jsonDepth) return;
  for (const [key, child] of Object.entries(value)) leaves(child, [...path, key], out);
}

/** The text as a JSON object, or undefined when it is not one. */
function jsonObject(text: string): object | undefined {
  const trimmed = text.trim();
  if (!trimmed.startsWith('{')) return undefined;
  try {
    const value: unknown = JSON.parse(trimmed);
    return value && typeof value === 'object' && !Array.isArray(value) ? value : undefined;
  } catch {
    return undefined;
  }
}

/** The numeric fields of a JSON object body (a response); nothing for any other text. */
export function readJsonMetrics(text: string): MetricReading[] {
  const value = jsonObject(text.slice(0, METRIC_LIMITS.textChars));
  const found: Array<Omit<MetricReading, 'name'>> = [];
  if (value) leaves(value, [], found);
  return named(found);
}

/**
 * The numbers a command printed: a JSON object's numeric fields when the whole output is one,
 * else every line that is a name and a number (`label: 12 ms`, `label = 12`), else the
 * `key=value` pairs inside a line. At most 50, in the order printed.
 */
export function readMetrics(text: string): MetricReading[] {
  const plain = text.slice(0, METRIC_LIMITS.textChars).replace(ANSI, '');
  if (jsonObject(plain)) return readJsonMetrics(plain);
  const found: Array<Omit<MetricReading, 'name'>> = [];
  for (const raw of plain.split(/\r?\n/)) {
    if (found.length >= METRIC_LIMITS.perSource) break;
    const line = raw.trim();
    if (!line || line.length > METRIC_LIMITS.lineChars) continue;
    const whole = LINE.exec(line);
    if (whole) {
      const value = metricValue(whole[2]!);
      if (value !== undefined)
        found.push({ label: label(whole[1]!), value, ...(whole[3] ? { unit: whole[3] } : {}) });
      continue;
    }
    for (const pair of line.matchAll(PAIR)) {
      const value = metricValue(pair[2]!);
      if (value !== undefined)
        found.push({ label: label(pair[1]!), value, ...(pair[3] ? { unit: pair[3] } : {}) });
    }
  }
  return named(found);
}

/**
 * One source's metrics: base and head readings with the same name and unit pair up (a unit that
 * changed is not converted: the head reading stands alone). Head's order first, then what only
 * base printed. At most 50.
 */
export function pairMetrics(
  base: readonly MetricReading[] = [],
  head: readonly MetricReading[] = [],
): PairedMetric[] {
  const before = new Map(base.map((m) => [m.name, m]));
  const after = new Map(head.map((m) => [m.name, m]));
  const out: PairedMetric[] = [];
  for (const h of head) {
    const b = before.get(h.name);
    const paired = b !== undefined && b.unit === h.unit;
    out.push({
      name: h.name,
      label: h.label,
      ...(h.unit ? { unit: h.unit } : {}),
      ...(paired ? { base: b.value } : {}),
      head: h.value,
    });
  }
  for (const b of base)
    if (!after.has(b.name))
      out.push({ name: b.name, label: b.label, ...(b.unit ? { unit: b.unit } : {}), base: b.value });
  return out.slice(0, METRIC_LIMITS.perSource);
}
```

```ts
 * step's changed pixels, the numeric fields of each response, the numbers each demo command

 * never becomes a metric. At most 50 per source and 500 per run.

function metricEvidence(
  sources: EvidenceSources,
  redact: (text: string) => string,

    for (const m of metrics) out.push(metricItem(source, path, m));

    text === undefined ? undefined : readJsonMetrics(redact(text));
  const files = sources.diff ?? [];
  if (files.length) {
    const lines = files.flatMap((f) => f.hunks.flatMap((h) => h.lines));
    const total = (kind: 'add' | 'del') => lines.filter((l) => l.kind === kind).length;
    add(metricSource.diff(), RUN_PATHS.diff, [
      { name: 'files', label: 'files', head: new Set(files.map((f) => f.path)).size },
      { name: 'additions', label: 'additions', head: total('add') },
      { name: 'deletions', label: 'deletions', head: total('del') },
    ]);
  }
  for (const s of sources.behavior?.scenarios ?? [])
    for (const step of s.steps)
      if (step.changedRatio !== undefined) {
        const share = Number((100 * step.changedRatio).toFixed(METRIC_LIMITS.decimals));
        add(metricSource.pixel(s.id, step.id), DEMO_PATHS.behaviorDiff, [
          {
            name: 'changed',
            label: `${s.name} (${s.viewport}) · ${step.id}`,
            unit: '%',
            head: share,
          },
        ]);
      }
  for (const [i, r] of (sources.demo?.requests ?? []).entries())
    add(
      metricSource.http(i + 1),
      DEMO_PATHS.captures,
      pairMetrics(json(r.before?.body), json(r.after.body)),
```

```ts
/*
 * How a video draws and derives numbers. Covi's own formatting, not `Intl`: the same digits on
 * every machine and in every language Covi speaks (en, ko, ja, zh all group thousands with commas
 * and write a point for decimals). DOM-free: the runtime bundles it, and Node resolves with it.
 */

/** Without a count, a compare's after value lands this many seconds into its element's clock. */
export const COMPARE_LANDS = 0.6;

/** A value as drawn: digits grouped by three, `decimals` after the point, a real minus sign. */
export function formatNumber(value: number, decimals: number): string {
  const fixed = Math.abs(value).toFixed(decimals);
  const [whole = '0', fraction] = fixed.split('.');
  const grouped = whole.replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  const sign = value < 0 && Number(fixed) !== 0 ? '−' : '';
  return `${sign}${grouped}${fraction ? `.${fraction}` : ''}`;
}

/**
 * The change from `from` to `to` in percent, as Covi draws it: whole percents from 10% up, one
 * decimal below. Undefined when `from` is 0, where no percentage means anything.
 */
export function percentChange(from: number, to: number): number | undefined {
  if (from === 0) return undefined;
  const percent = ((to - from) / Math.abs(from)) * 100;
  const rounded = Math.abs(percent) >= 10 ? Math.round(percent) : Math.round(percent * 10) / 10;
  return rounded || 0;
}

/** A change in percent as drawn: `−86%`, `+4.5%`, `0%`. */
export function formatPercent(percent: number): string {
  const sign = percent > 0 ? '+' : percent < 0 ? '−' : '';
  return `${sign}${formatNumber(Math.abs(percent), Number.isInteger(percent) ? 0 : 1)}%`;
}

/** A count beat, in seconds of the clock its element is drawn with. */
export interface CountSpan {
  t: number;
  seconds: number;
}

/** How far a count has come at `t`, eased out: quick at first, settling onto the value. */
export function countProgress(t: number, count: CountSpan | undefined): number {
  if (!count) return 1;
  const k = Math.min(1, Math.max(0, (t - count.t) / Math.max(1e-6, count.seconds)));
  return 1 - (1 - k) ** 3;
}

/** The value a count shows `progress` (0–1) of the way from `from` to `to`, as printed. */
export function tickValue(from: number, to: number, progress: number, decimals: number): number {
  if (progress >= 1) return to;
  if (progress <= 0) return from;
  return Number((from + (to - from) * progress).toFixed(decimals)) || 0;
}
```

```ts
import type { DirectionElement } from '../../timeline/types.ts';

  drawnFont,

  overflows,

  COMPARE_LANDS,
  type CountSpan,
  countProgress,

/*
 * A measured number, drawn: a counter (the value large, ticking from before to after), bars on one
 * scale, or the two values side by side. Every value and unit comes from the run's evidence and
 * every derived number is Covi's; all text is set as text. A pure function of the element's clock.
 */

type MetricElement = Extract<DirectionElement, { kind: 'metric' }>;

/** The counter's value, in design units: as large as fits, and at least the floor while it fits. */
export const COUNTER_FONT = { max: 300, floor: 120, fallback: 48 } as const;

export function metric(e: MetricElement, ctx: ComponentContext, count?: CountSpan): Component {
  if (e.show === 'bars' && e.from !== undefined) return bars(e, e.from, ctx, count);
  if (e.show === 'compare' && e.from !== undefined) return compare(e, e.from, ctx, count);
  return counter(e, ctx, count);
}

/** The card a metric is drawn on: its whole slot, the content centered in it. */
function card(e: MetricElement, ctx: ComponentContext, className: string): HTMLDivElement {
  const box = el('div', `mcard ${className}`, ctx.root);
  place(box, e.rect);
  return box;
}

/** The width inside a card's padding, in pixels. */
const inner = (box: HTMLElement, ctx: ComponentContext) => box.clientWidth - 2 * ctx.u(32);

/** Whether a node's text fits `room` at its current size. */
function fits(node: HTMLElement, room: { maxWidth: number; maxHeight: number }): boolean {
  return node.scrollWidth <= room.maxWidth + 1 && node.scrollHeight <= room.maxHeight + 1;
}

/**
 * The largest size at which every one of `texts` fits `room`, set on `node`: the size the text
 * keeps while a count ticks through them (tabular digits, so no value is wider than these). Below
 * the floor only when a text cannot fit at it.
 */
function fitAll(
  node: HTMLElement,
  target: HTMLElement,
  texts: readonly string[],
  sizes: { max: number; floor: number; fallback: number },
  room: { maxWidth: number; maxHeight: number },
): number {
  let size = sizes.max;
  for (const text of texts) {
    target.textContent = text;
    let s = fitText(node, { max: sizes.max, min: sizes.floor, ...room });
    if (!fits(node, room)) s = fitText(node, { max: sizes.floor, min: sizes.fallback, ...room });
    size = Math.min(size, s);
  }
  node.style.fontSize = `${size}px`;
  return size;
}

/** The value shown at `t`: ticking from `from` to `to` during a count, else `to`. */
function shownValue(e: MetricElement, from: number | undefined, t: number, count?: CountSpan) {
  return from === undefined || !count
    ? e.to
    : tickValue(from, e.to, countProgress(t, count), e.decimals);
}

/** The delta appears as the count lands, or with the element when nothing counts. */
function deltaOpacity(t: number, count?: CountSpan): number {
  return count ? seg(t, count.t + 0.85 * count.seconds, count.t + count.seconds + 0.25) : 1;
}

/** A text box as QC reads it: body text, its size as drawn. */
const textItem = (node: HTMLElement): LayoutItem => ({
  role: 'text',
  rect: rectOf(node),
  overflow: overflows(node),
  font: drawnFont(node),
  text: 'body',
});

const visible = (node: HTMLElement) => Number.parseFloat(node.style.opacity || '1') > 0;

function counter(e: MetricElement, ctx: ComponentContext, count?: CountSpan): Component {
  const u = ctx.u;
  const tall = ctx.timeline.orientation === 'vertical';
  const box = card(e, ctx, 'mcounter');
  const name = el('div', 'mname', box, e.name);
  const row = el('div', 'mrow', box);
  const value = el('span', 'mvalue', row);
  if (e.unit) el('span', 'munit', row, e.unit);
  const delta =
    e.delta === undefined ? undefined : el('div', 'mdelta', box, formatPercent(e.delta));
  const width = inner(box, ctx);
  fitText(name, { max: u(tall ? 48 : 44), min: u(28), maxWidth: width });
  const printed = [e.to, ...(e.from === undefined ? [] : [e.from])].map((v) =>
    formatNumber(v, e.decimals),
  );
  const size = fitAll(
    row,
    value,
    printed,
    { max: u(COUNTER_FONT.max), floor: u(COUNTER_FONT.floor), fallback: u(COUNTER_FONT.fallback) },
    { maxWidth: width, maxHeight: 0.55 * e.rect.height },
  );
  if (delta) delta.style.fontSize = `${Math.max(u(36), 0.28 * size)}px`;
  let shown = '';
  return {
    update(clock) {
      const now = formatNumber(shownValue(e, e.from, clock.t, count), e.decimals);
      if (now !== shown) value.textContent = shown = now;
      if (delta) delta.style.opacity = deltaOpacity(clock.t, count).toFixed(3);
    },
    report: () => [
      { role: 'media', rect: rectOf(box) },
      textItem(name),
      // The value's size, unit beside it: what QC and the "largest text" test read.
      { ...textItem(row), font: drawnFont(value) },
      ...(delta ? [textItem(delta)] : []),
    ],
  };
}

function bars(e: MetricElement, from: number, ctx: ComponentContext, count?: CountSpan): Component {
  const u = ctx.u;
  const labels = ctx.timeline.labels;
  const box = card(e, ctx, 'mbars');
  const name = el('div', 'mname', box, e.name);
  const unit = e.unit ? `${e.unit === '%' ? '' : ' '}${e.unit}` : '';
  // One grid for both rows, so the two tracks start and end together.
  const grid = el('div', 'mgrid', box);
  const rows = [
    { caption: labels?.before ?? 'Before', tone: 'base' },
    { caption: labels?.after ?? 'After', tone: 'head' },
  ].map(({ caption, tone }) => {
    const cap = el('div', `mcap ${tone}`, grid, caption);
    const fill = el('div', `mfill ${tone}`, el('div', 'mtrack', grid));
    const num = el('div', `mnum ${tone}`, grid);
    return { cap, fill, num };
  });
  const delta =
    e.delta === undefined ? undefined : el('div', 'mdelta', box, formatPercent(e.delta));
  const most = u(ctx.timeline.orientation === 'vertical' ? 52 : 48);
  box.style.fontSize = `${Math.min(most, Math.max(u(28), e.rect.height / 9))}px`;
  // The values' column fits the wider value, so a count never moves the tracks.
  const widest = Math.max(
    ...[from, e.to].map((v) => {
      rows[0]!.num.textContent = `${formatNumber(v, e.decimals)}${unit}`;
      return rows[0]!.num.scrollWidth;
    }),
  );
  for (const r of rows) r.num.style.minWidth = `${Math.ceil(widest) + 2}px`;
  // One scale for both: the larger magnitude fills the track.
  const scale = Math.max(Math.abs(from), Math.abs(e.to)) || 1;
  return {
    update(clock) {
      const head = shownValue(e, from, clock.t, count);
      [from, head].forEach((v, i) => {
        const r = rows[i]!;
        r.fill.style.width = `${((100 * Math.abs(v)) / scale).toFixed(3)}%`;
        const t = `${formatNumber(v, e.decimals)}${unit}`;
        if (r.num.textContent !== t) r.num.textContent = t;
      });
      if (delta) delta.style.opacity = deltaOpacity(clock.t, count).toFixed(3);
    },
    report: () => [
      { role: 'media', rect: rectOf(box) },
      textItem(name),
      ...rows.flatMap((r) => [textItem(r.cap), textItem(r.num)]),
      ...(delta ? [textItem(delta)] : []),
    ],
  };
}

function compare(
  e: MetricElement,
  from: number,
  ctx: ComponentContext,
  count?: CountSpan,
): Component {
  const u = ctx.u;
  const labels = ctx.timeline.labels;
  const box = card(e, ctx, 'mcompare');
  const name = el('div', 'mname', box, e.name);
  const pair = el('div', 'mpair', box);
  const side = (caption: string, tone: string) => {
    const s = el('div', `mside ${tone}`, pair);
    el('div', 'mcap', s, caption);
    const num = el('div', 'mnum', s);
    return { s, num };
  };
  const base = side(labels?.before ?? 'Before', 'base');
  const arrow = el('div', 'marrow', pair, '→');
  const head = side(labels?.after ?? 'After', 'head');
  const delta =
    e.delta === undefined ? undefined : el('div', 'mdelta', box, formatPercent(e.delta));
  const unit = e.unit ? `${e.unit === '%' ? '' : ' '}${e.unit}` : '';
  const width = inner(box, ctx);
  fitText(name, { max: u(44), min: u(28), maxWidth: width });
  // Each side gets the width left of the arrow, halved; both draw at one size.
  const room = { maxWidth: (width - u(140)) / 2, maxHeight: 0.4 * e.rect.height };
  const printed = [from, e.to].map((v) => `${formatNumber(v, e.decimals)}${unit}`);
  const sizes = { max: u(160), floor: u(64), fallback: u(36) };
  const size = Math.min(
    fitAll(base.num, base.num, printed, sizes, room),
    fitAll(head.num, head.num, printed, sizes, room),
  );
  for (const n of [base.num, head.num]) n.style.fontSize = `${size}px`;
  arrow.style.fontSize = `${0.8 * size}px`;
  if (delta) delta.style.fontSize = `${Math.max(u(36), 0.45 * size)}px`;
  base.num.textContent = printed[0]!;
  // The head lands last: after the arrow, on its count, or COMPARE_LANDS in.
  const start = count ? count.t : COMPARE_LANDS;
  let shown = '';
  return {
    update(clock) {
      const t = clock.t;
      const now = `${formatNumber(shownValue(e, from, t, count), e.decimals)}${unit}`;
      if (now !== shown) head.num.textContent = shown = now;
      arrow.style.opacity = seg(t, start - 0.3, start).toFixed(3);
      rise(head.s, seg(t, start - 0.1, start + 0.3), u(24));
      if (delta)
        delta.style.opacity = (
          count ? deltaOpacity(t, count) : seg(t, start + 0.3, start + 0.6)
        ).toFixed(3);
    },
    report: () => [
      { role: 'media', rect: rectOf(box) },
      textItem(name),
      textItem(base.num),
      // The head is reported once it has begun to land.
      ...(visible(head.s) ? [textItem(head.num)] : []),
      ...(delta ? [textItem(delta)] : []),
    ],
  };
}
```

```ts
import { decimalsOf, METRIC_LIMITS } from '@covi/core';
import { percentChange } from '../runtime/numbers.ts';
import type { DirectionElement, Rect, TimelineLabels } from '../timeline/types.ts';
import type { ShotElement } from './schema.ts';
import type { MetricSource } from './sources.ts';

/*
 * Metric elements: what a shot may ask of a measured number, and the number as the video draws it.
 * Values and units come from the run's evidence; the change in percent is Covi's.
 */

export type MetricShotElement = Extract<ShotElement, { kind: 'metric' }>;

/** The sides a metric has, as a message names them: `a head value`, `a base and a head value`. */
function sides(metric: MetricSource): string {
  const has = [
    ...(metric.base === undefined ? [] : ['base']),
    ...(metric.head === undefined ? [] : ['head']),
  ];
  return `${has.join(' and ')} value`;
}

/** What a metric element asks of its metric that the metric does not have, as problems. */
export function metricProblems(element: MetricShotElement, metric: MetricSource): string[] {
  const out: string[] = [];
  const show = element.show ?? 'counter';
  const both = metric.base !== undefined && metric.head !== undefined;
  if (show !== 'counter' && element.side)
    out.push(`show "${show}" draws both sides; leave "side" out`);
  else if (element.side && metric[element.side] === undefined)
    out.push(`side "${element.side}": "${element.evidence}" has only a ${sides(metric)}`);
  if (show !== 'counter' && !both)
    out.push(
      `show "${show}" needs a base and a head value, and "${element.evidence}" has only a ${sides(metric)}`,
    );
  return out;
}

/**
 * Why a `count` beat cannot tick `element` from its base value to its head value, or nothing when
 * it can. A missing element is reported by the reference check already.
 */
export function countProblem(
  element: ShotElement | undefined,
  metric: MetricSource | undefined,
): string | undefined {
  if (!element) return undefined;
  if (element.kind !== 'metric')
    return `count ticks a metric element, and "${element.id}" is a ${element.kind}`;
  if (element.side)
    return `count ticks from base to head, and "${element.id}" shows only its ${element.side} side`;
  if (metric && (metric.base === undefined || metric.head === undefined))
    return `count needs a base and a head value, and "${element.evidence}" has only a ${sides(metric)}`;
  return undefined;
}

/** The diff's totals carry Covi's own words for them, which the video says in its language. */
const DIFF_NAMES = { files: 'files', additions: 'added', deletions: 'removed' } as const;

/** What a metric is called on screen: the diff's totals in the video's words, else what the output printed. */
function metricName(metric: MetricSource, labels: Pick<TimelineLabels, 'stats'>): string {
  const total = /^metric:diff:(files|additions|deletions)$/.exec(metric.id)?.[1] as
    | keyof typeof DIFF_NAMES
    | undefined;
  return total ? labels.stats[DIFF_NAMES[total]] : metric.name;
}

/**
 * A metric element as the video draws it: a counter shows its one side, or ticks from base to head
 * when the metric has both; bars and compare show both. Nothing when the metric lacks what the
 * element shows (a validated direction never does).
 */
export function resolveMetric(
  e: MetricShotElement,
  metric: MetricSource | undefined,
  rect: Rect,
  labels: Pick<TimelineLabels, 'stats'>,
): Extract<DirectionElement, { kind: 'metric' }> | undefined {
  if (!metric) return undefined;
  const show = e.show ?? 'counter';
  const both = metric.base !== undefined && metric.head !== undefined;
  let from: number | undefined;
  let to: number | undefined;
  if (show !== 'counter') {
    if (!both) return undefined;
    from = metric.base;
    to = metric.head;
  } else if (e.side) to = metric[e.side];
  else if (both) {
    from = metric.base;
    to = metric.head;
  } else to = metric.head ?? metric.base;
  if (to === undefined) return undefined;
  const decimals = Math.min(
    METRIC_LIMITS.decimals,
    Math.max(decimalsOf(to), from === undefined ? 0 : decimalsOf(from)),
  );
  const delta = from === undefined ? undefined : percentChange(from, to);
  return {
    id: e.id,
    kind: 'metric',
    rect,
    show,
    name: e.label ?? metricName(metric, labels),
    ...(metric.unit ? { unit: metric.unit } : {}),
    ...(from === undefined ? {} : { from }),
    to,
    decimals,
    ...(delta === undefined ? {} : { delta }),
  };
}
```

```ts
/** A counter needs at least this many printable steps between its values to tick; fewer compare. */
export const COUNTER_STEPS = 10;

/**
 * How much a metric changed, for choosing the one to show: how many times larger or smaller its
 * magnitude became, each plus one (a fold change with a pseudocount), so `1 → 0` (one timeout
 * gone) does not outrank `70406 → 9907` (the request shrank sevenfold).
 */
export function metricChange(base: number, head: number): number {
  return Math.abs(Math.log1p(Math.abs(head)) - Math.log1p(Math.abs(base)));
}

/**
 * The metric a terminal scene's command measured that changed most between base and head (the
 * earliest on a tie), or nothing: a scene that shows no command, a command that printed nothing
 * measurable at both revisions, or nothing that changed. Read from what the scene shows, never
 * from what it cites.
 */
export function keyMetric(
  scene: Pick<Scene, 'visual'>,
  evidence: EvidenceIndex | undefined,
): EvidenceItem | undefined {
  if (scene.visual.kind !== 'terminal' || !evidence) return undefined;
  const prefixes = sceneEvidence({ visual: scene.visual }, evidence).flatMap((id) => {
    const n = /^terminal:(\d+)$/.exec(id);
    return n ? [`metric:${metricSource.terminal(Number(n[1]))}:`] : [];
  });
  let best: EvidenceItem | undefined;
  let most = 0;
  for (const item of evidence.items) {
    const m = item.metric;
    if (item.kind !== 'metric' || m?.base === undefined || m.head === undefined) continue;
    if (!prefixes.some((p) => item.id.startsWith(p))) continue;
    const change = metricChange(m.base, m.head);
    if (change > most) {
      best = item;
      most = change;
    }
  }
  return best;
}

/**
 * The default director's shot for a terminal scene with a key metric: the number beside the
 * output it came from (above it in a tall frame), counted so it lands as the narration names it,
 * or, when the change has too few steps to tick, revealed as a before/after comparison.
 */
export function metricShot(
  scene: Pick<Scene, 'visual' | 'narration'>,
  evidence: EvidenceIndex | undefined,
  orientation: Orientation,
): Pick<Shot, 'layout' | 'elements' | 'beats'> | undefined {
  const item = keyMetric(scene, evidence);
  const m = item?.metric;
  if (!item || m?.base === undefined || m.head === undefined) return undefined;
  const decimals = Math.min(
    METRIC_LIMITS.decimals,
    Math.max(decimalsOf(m.base), decimalsOf(m.head)),
  );
  const show = Math.abs(m.head - m.base) * 10 ** decimals >= COUNTER_STEPS ? 'counter' : 'compare';
  // Where the narration says it: its printed name, else its value as drawn or as printed.
  const text = parseEmphasis(scene.narration).text;
  const at = [item.label, formatNumber(m.head, decimals), String(m.head)].find(
    (phrase) => phrase.trim() && findPhrase(text, phrase).count === 1,
  );
  const elements: ShotElement[] = [
    { id: 'metric', kind: 'metric', evidence: item.id, show },
    { id: 'visual', kind: 'visual' },
  ];
  return {
    layout: orientation === 'vertical' ? 'column' : 'row',
    elements,
    beats: [
      show === 'counter'
        ? { verb: 'count', element: 'metric', ...(at ? { at } : {}) }
        : { verb: 'reveal', element: 'metric', style: 'pop', ...(at ? { at } : {}) },
    ],
  };
}
```

## Rulings

- Ruling: metric evidence comes from exactly the spec's five sources — demo commands, requests (JSON object bodies only), behavior-diff steps' changed-pixel share, the diff's totals, and the test run — and behavior-diff timings are left out — timings measure the runner's machine, not the change (0.2.0 already refuses to call a scenario changed from timing alone), and the spec lists only the pixel share — an agent cannot cite a flow's duration; it can still show a command that prints one.
- Ruling: a line counts only when it is entirely `label: number [unit]` or `label = number [unit]` (a leading `-`, `*`, or `•` allowed); other lines give only `key=value` pairs bounded by spaces, commas, semicolons, or brackets; anything after the unit (`timeouts: 1 (retried)`) makes the line silent — silence over noise (AGENTS.md): versions, times, dates, ports, and prose stay out of the registry — an honest number followed by commentary is not citable unless the program prints it on its own line.
- Ruling: there is no format-specific reader for test runners (TAP's `# pass 5`, vitest's summary) — one deterministic reader for every text; the spec's patterns only — most test runs give no metrics today.
- Ruling: JSON is read only when the whole text is one JSON object; numeric leaves through object keys only, never inside arrays, to depth 4 — array elements are records whose numbers are ids and amounts — a percentile inside an array (`[{"p95": 12}]`) is not citable.
- Ruling: thousands separators are one of `,`, `_`, U+00A0, U+202F, U+2009 throughout a number, in groups of three; anything else (`1,5`, `1.234,56`) makes the line silent — a decimal comma is ambiguous with grouping — European-formatted output gives no metrics.
- Ruling: `metric.name` is the slug that ends the id (as the spec's id rule says), and the item's `label` keeps what the output printed (`request bytes`, `page.size`), which the video draws; a label without ASCII letters is named `value`, `value-2`, … — ids must be `[a-z0-9-]` and the display needs the printed words — metrics from output in other scripts get uninformative ids, though they draw their own label.
- Ruling: base and head pair only when name and unit match; a changed unit is not converted and the head reading stands alone — conversion is a guess — a `1.2 s → 800 ms` change cannot be counted.
- Ruling: a source's metrics follow head's printed order, then base-only names; metric items follow every other item in the registry, in source order (diff, pixel steps, requests, commands, test run), capped at 50 per source after pairing and 500 per run — existing items keep their positions, so nothing else in the registry moves — a run with very many sources loses its last sources' metrics (the test run's first).
- Ruling: the diff's totals and a step's changed-pixel share are single values on the head side — the schema needs a side, and they describe the change as it stands at head — `count`, `bars`, and `compare` cannot use them; a counter can.
- Ruling: an evidence item is `kind: 'metric'` exactly when it carries `metric` (a schema refinement) — readers never guess — none.
- Ruling: `describeMetric` (`label: base → head unit`) is what `covi evidence`, the model prompt's captured-evidence list, and reports' cited evidence show for a metric — a cited number reads as what it says wherever it appears — prompt lines grow by a few characters per metric.
- Ruling: `METRIC_LIMITS`, `decimalsOf`, and `isMetricValue` live in `model/evidence.ts` beside the schema they bound — one source of truth for the bounds — none.
- Ruling: the counter's value is fitted once, at mount, to the wider of its two printed values (tabular digits) and keeps that size through the count, between 120 and 300 design units, dropping below 120 (to 48) only when the number cannot fit its slot — no jitter or overflow mid-count — a 15-digit number in a narrow slot draws under 120 without a QC warning.
- Ruling: digits are grouped with commas and decimals written with a point in every language Covi speaks (en, ko, ja, zh), with U+2212 for minus — all four write 70,406 — a viewer used to other grouping reads Covi's.
- Ruling: the delta is a percentage only (whole from 10% up, one decimal below, absent from a base of 0), drawn in the theme's primary color, never judged good or bad — fewer bytes is good and fewer passing tests is bad, and Covi does not know which — viewers read direction from the sign alone.
- Ruling: a `count` with `at` lands on its phrase (it ticks for the 1.6 s before it, at least 0.6 s, never before the scene starts); without `at` it starts at its spaced slot like other beats — the number on screen should be the number being said — agents used to `reveal`/`camera` starting on their phrase must read the docs and the skill, which say it.
- Ruling: a count lasts 1.6 s with an ease-out cubic; bars' head bar follows the same progress; a compare's after value lands 0.6 s into the element's clock (or on its count); the delta fades in over the count's last 15% — the spec leaves lengths open — retuning is a constant change.
- Ruling: `show` defaults to `counter`; `side` is allowed only on a counter; `bars` and `compare` need both values; `count` needs a metric element without `side` whose metric has both values, at most once per element — explicit rules the validator can name — a one-sided count from zero waits for B5's `count-up`.
- Ruling: the default director gives a terminal scene a metric when its command printed metrics with both sides that differ, choosing the largest `|ln(1+|head|) − ln(1+|base|)|` (a fold change with a pseudocount of one), earliest on ties — plain relative change ranks `timeouts 1 → 0` (−100%) above `request bytes 70406 → 9907` (−86%); the pseudocount keeps a one-unit change in a small count from outranking a large measured change — a story whose headline really is one timeout gone needs an agent's direction.
- Ruling: the director draws a `counter` with a `count` when the change has at least 10 printable steps, else a `compare` revealed with `pop` — a counter needs steps to tick through — small counts never tick by default.
- Ruling: the director's beat lands on the metric's printed name in the narration when it occurs exactly once, else on the head value as drawn or as printed, else it is spread — Covi's drafted terminal narration quotes the output line ("It now prints request bytes: 9907"), so the count lands as the narrator names the number — narration that names neither gets a spread count.
